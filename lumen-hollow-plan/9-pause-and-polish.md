# Milestone 9 — Pause + UI/Gameplay Polish

Read `@plan/00-OVERVIEW.md` first.

## Pause

Add:
- PAUSED
- RESUME
- RESTART LEVEL
- MAIN MENU

When paused:
- Gameplay stops
- Physics stops
- Enemies stop
- Timer stops
- Gameplay animations stop

On resume everything continues correctly.

## Polish

Add where appropriate:
- Fade transitions
- Button hover/press feedback
- Checkpoint activation animation
- Treasure opening animation
- Level completion animation
- Timer warning effects
- Particle effects
- Screen shake
- Smooth camera movement
- Sound effects
- Background music if available

Keep the Lumen Hollow identity.

## Responsive UI

Verify:
- Desktop
- Laptop
- Mobile
- Portrait/landscape
- No browser scrolling
- No accidental zoom
- Correct canvas scaling
- No cropped gameplay

Do not add polish at the expense of performance.

## Test

Test every game state and transition.
Test pause during:
- normal movement
- enemy interaction
- puzzle interaction
- timer countdown
- near timeout

Do not commit.
